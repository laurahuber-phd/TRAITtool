# Trophic Rapid Assessment and Integration Toolkit (TRAITtool)  

TRAITtool is an analysis toolkit for biodiversity survey data to draw a connection between species and the habitats they rely on using natural history information.. It provides analyses that can be used directly with little bioinformatic knowledge needed.

To use TRAITtool, clone this repository. All required files to run TRAIttool on your personal machine should be included in the repository.
